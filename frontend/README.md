# Berichter — cleanup edition

## Запуск
Из каталога berichter:

    uv run python3 -m http.server 80

Сборка и npm не требуются. Нативные ES-модули загружаются браузером через HTTP.
Не открывайте index.html через file://. Адрес backend — в config.js.
Если у вас уже настроен свой API, сохраните своё значение apiBase.

## Структура
index.html — разметка.
config.js — публичная конфигурация API.
assets/styles.css — компоненты и адаптивная компоновка.
assets/js/app.js — состояние, отображение, обработчики и запуск.
assets/js/dates.js — календарные функции.
assets/js/http.js — адрес API и обработка ошибок.

## Изменения
- Навигация мышью/касанием больше не фокусирует заголовок.
- При клавиатурной активации меню фокус переносится на заголовок;
  индикатор компактный, по ширине текста, а не всей страницы.
- Общий :focus-visible заменён правилами для интерактивных элементов.
- Ненужные animationend и классы ai-on/is-generating удалены.
- Объединено открытие дня из архива и списка пропусков.
- Для динамических кнопок используется общий делегированный обработчик.
- Исправлен порядок: раздел показывается до фокусировки поля.
- Иконка обновления не стирается при изменении подписи кнопки.
- Очищенный пользователем черновик тоже учитывается при уходе со страницы.
- Повторное копирование не восстанавливает неверную подпись кнопки таймером.
- Инициализация собрана после объявления состояния и обработчиков.
- Общие функции выделены в модули; обращения к статичным DOM-элементам кешируются.
- Совпадающие CSS-селекторы объединены в рамках своих медиаблоков.
- Исправлен регистр SVG viewBox; viewport включает safe-area.

## Что намеренно сохранено
Версии запросов и AbortController: это защита от гонок, а не ненужное дублирование.
Проверка фактического сохранения после генерации.
Запасные способы копирования и ручное копирование.
Существующие API-контракты и лимит 400 символов.
Нижняя навигация на телефонах.
